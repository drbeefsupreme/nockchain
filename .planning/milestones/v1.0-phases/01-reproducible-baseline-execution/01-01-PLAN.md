  <action>
Create `benchmarks/baseline/sol-baseline.toml` with three sections:

```toml
[defaults]
fixtures_dir = "bench-artifacts/fixtures"
output_root = "bench-artifacts/sol-baseline"
passes = 2
enable_checkpointing = false
envs = "native"
docker_memory = "16g"

[quick]
passes = 1

[full]
passes = 5
envs = "native,docker"
docker_memory = "16g"
```

Create `crates/nockchain-bench/src/speed_of_light/config.rs` with:
- `BaselineConfig` struct with all fields from `[defaults]` (serde Deserialize + Serialize)
- `ProfileOverrides` struct matching profile sections (all fields Optional)
- `ConfigFile` struct with `defaults: BaselineConfig`, `quick: Option<ProfileOverrides>`, `full: Option<ProfileOverrides>`
- `load_config(path: &Path, profile: &str) -> Result<BaselineConfig>` that:
  1. Reads TOML file
  2. Starts with defaults
  3. Merges selected profile overrides on top (only non-None fields)
  4. Returns resolved config
- `dump_shell_vars(config: &BaselineConfig) -> String` that emits `KEY=VALUE` lines (one per field, uppercase keys like `PASSES=5`, `FIXTURES_DIR=bench-artifacts/fixtures`, `ENABLE_CHECKPOINTING=false`)
- `config_sha256(path: &Path) -> Result<String>` that returns SHA-256 hex digest of the raw config file content

Add `pub mod config;` to `crates/nockchain-bench/src/speed_of_light/mod.rs`.

Note: The `toml` crate (0.8) is already in Cargo.toml. Use sha2 crate for hashing -- add `sha2 = "0.10"` to `[dependencies]` in Cargo.toml if not present.
  </action>

    <manual>Config module compiles without errors</manual>
  </verify>
  <done>BaselineConfig loads from TOML, merges profile overrides, dumps shell vars, and computes config hash. Module compiles cleanly.</done>
