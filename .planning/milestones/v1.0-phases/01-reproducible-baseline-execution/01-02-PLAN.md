```rust
use serde::{Deserialize, Serialize};

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct RunProvenance {
    pub schema_version: String,         // "1"
    pub timestamp: String,              // ISO 8601
    pub git_commit: String,             // Full SHA
    pub git_branch: String,             // Branch name
    pub benchmark_config: serde_json::Value, // Full embedded resolved config
    pub config_sha256: String,          // SHA-256 hex of raw config file
    pub environment: EnvironmentInfo,
    pub tool_versions: ToolVersions,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct EnvironmentInfo {
    pub os: String,                     // e.g., "Linux 6.17.0-14-generic x86_64"
    pub kernel: String,                 // Kernel version
    pub cpu_model: String,
    pub cpu_cores: u32,
    pub cpu_frequency_mhz: Option<u64>, // May not be available
    pub ram_bytes: u64,
    pub active_cgroups: Option<String>, // Cgroup limits if applicable
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct ToolVersions {
    pub rustc: String,
    pub cargo: String,
    pub nockchain_bench: String,
}
```

Implement:
- `validate_manifest(provenance: &RunProvenance) -> Result<(), Vec<String>>` that checks:
  1. `schema_version` is "1"
  2. `git_commit` is exactly 40 hex chars
  3. `git_branch` is non-empty
  4. `timestamp` is non-empty and contains "T" (basic ISO 8601 check)
  5. `config_sha256` is exactly 64 hex chars
  6. `environment.os` is non-empty
  7. `environment.cpu_cores` > 0
  8. `environment.ram_bytes` > 0
  9. `tool_versions.rustc` is non-empty
  Returns Ok(()) if all pass, Err(vec of failure descriptions) otherwise.
  Strict: ANY missing or invalid field causes rejection.

- `write_manifest(provenance: &RunProvenance, path: &Path) -> Result<(), std::io::Error>` that:
  1. Calls `validate_manifest` first -- returns error if validation fails
  2. Serializes to pretty JSON via serde_json
  3. Writes to the given path
  4. Returns Ok on success

Add to `crates/nockchain-bench/src/speed_of_light/guard/mod.rs`:
```rust
pub mod provenance;
pub use provenance::{RunProvenance, EnvironmentInfo, ToolVersions, validate_manifest, write_manifest};
```
