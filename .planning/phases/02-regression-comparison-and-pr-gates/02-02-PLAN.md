**Create `.github/workflows/sol-pr-regression.yml`:**

PR-triggered workflow that compares candidate artifacts against cached baseline.

```yaml
name: SOL PR Regression Check

on:
  pull_request:
    branches: [master]

permissions:
  pull-requests: write
  contents: read
```

**Job: `regression-check`** on `ubuntu-latest`, timeout 30 minutes:

Steps:

1. **Checkout** — `actions/checkout@v4`

2. **Install Rust toolchain** — `dtolnay/rust-toolchain@stable`

3. **Cache cargo build** — `actions/cache@v4` with same key pattern as sol-baseline.yml (`${{ runner.os }}-cargo-bench-${{ hashFiles('**/Cargo.lock') }}`)

4. **Build nockchain-bench** — `cargo build --release -p nockchain-bench`

5. **Build fixtures** — same conditional fixture build as sol-baseline.yml

6. **Generate candidate baseline** — Run `bash scripts/sol_baseline_ci.sh --profile quick` to produce candidate artifacts in `bench-artifacts/sol-baseline/latest/`. Use `quick` profile for speed since this is PR-time. NOTE: Per user decision, the PR workflow "compares pre-existing artifacts only" — but since artifacts must exist, the workflow generates them with the quick profile. The candidate TSV will be at `bench-artifacts/sol-baseline/latest/data/combined_summary.tsv`.

7. **Restore baseline reference cache** — `actions/cache/restore@v4`:
   - `path: .cache/sol-baseline-ref/`
   - `key: sol-baseline-ref-v1-` (intentionally partial — won't exact-match, falls through to restore-keys)
   - `restore-keys: sol-baseline-ref-v1-`
   - `id: baseline-cache`
   - Do NOT set `fail-on-cache-miss: true`

8. **Run regression comparison** — Bash step:
   ```bash
   CANDIDATE="bench-artifacts/sol-baseline/latest/data/combined_summary.tsv"
   BASELINE=".cache/sol-baseline-ref/combined_summary.tsv"
   mkdir -p comparison

   if [ ! -f "$BASELINE" ]; then
     echo "## SOL Regression: No baseline available" >> "$GITHUB_STEP_SUMMARY"
     echo "No cached baseline found. Run the baseline workflow on master first." >> "$GITHUB_STEP_SUMMARY"
     echo "SOL_NO_BASELINE=true" >> "$GITHUB_ENV"
     exit 0
   fi

   bash scripts/sol_compare_ci.sh \
     --candidate "$CANDIDATE" \
     --baseline "$BASELINE" \
     --output-json comparison/delta.json \
     --output-md comparison/summary.md

   # Append to GitHub Actions step summary
   cat comparison/summary.md >> "$GITHUB_STEP_SUMMARY"
   ```

9. **Post PR comment** — Conditional on baseline existing:
   ```yaml
   if: env.SOL_NO_BASELINE != 'true'
   env:
     GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
   run: |
     gh pr comment "${{ github.event.pull_request.number }}" \
       --body-file comparison/summary.md \
       --repo "${{ github.repository }}"
   ```

10. **Upload comparison artifacts** — `actions/upload-artifact@v4`:
    - `name: sol-regression-${{ github.event.pull_request.number }}-${{ github.run_number }}`
    - `path: comparison/`
    - `if-no-files-found: ignore`
    - `retention-days: 30`

**IMPORTANT:** The entire workflow always exits 0 (advisory only). No step should use `continue-on-error: false` in a way that blocks the check. The comparison script itself exits 0 per Plan 01's design.

**Update `.github/workflows/sol-baseline.yml`:**

Add a trigger for `push` to `master` (in addition to existing `workflow_dispatch`):

```yaml
on:
  workflow_dispatch:
    inputs:
      profile:
        # ... existing config unchanged
  push:
    branches: [master]
    paths:
      - 'crates/nockchain-bench/**'
      - 'benchmarks/**'
      - 'scripts/sol_*'
```

Add a new step AFTER the existing "Upload artifacts" step:

```yaml
- name: Save baseline reference cache
  if: github.event_name == 'push' && github.ref == 'refs/heads/master'
  run: |
    mkdir -p .cache/sol-baseline-ref
    cp bench-artifacts/sol-baseline/latest/data/combined_summary.tsv .cache/sol-baseline-ref/combined_summary.tsv
    echo "Baseline reference updated from ${{ github.sha }}"

- name: Cache baseline reference
  if: github.event_name == 'push' && github.ref == 'refs/heads/master'
  uses: actions/cache/save@v4
  with:
    path: .cache/sol-baseline-ref/
    key: sol-baseline-ref-v1-${{ github.sha }}
```

For the push trigger, use default profile `full` (hardcode in the run step with a conditional):

```yaml
- name: Run baseline
  run: |
    PROFILE="${{ inputs.profile || 'full' }}"
    bash scripts/sol_baseline_ci.sh \
      --profile "$PROFILE" \
      --branch-bin "${{ inputs.branch_bin || 'main=target/release/nockchain-bench' }}"
```

Also update permissions to include `contents: read` (already present).
