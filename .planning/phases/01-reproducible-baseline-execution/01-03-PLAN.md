Create `scripts/sol_baseline_run.sh` as the single deterministic entrypoint. Structure:

```bash
#!/usr/bin/env bash
set -euo pipefail
```

**Usage/help:** Accept these flags:
- `--config <path>` (default: `benchmarks/baseline/sol-baseline.toml`)
- `--profile <quick|full>` (default: `quick`)
- `--branch-bin <name=path>` (required, passed through to sol_bench_matrix.sh; supports multiple)
- `--docker-image <name=image>` (optional, passed through)
- `--output-root <dir>` (overrides config value)
- `--passes <N>` (overrides config value)
- `--verbose` / `--quiet` (verbosity control)
- `--allow-dirty` (escape hatch for CI, NOT advertised in --help for local use)
- `-h` / `--help`

**Step 1: Dirty tree guard**
Unless `--allow-dirty` is set:
```bash
if ! git diff --quiet || ! git diff --cached --quiet; then
  echo "ERROR: Working tree is dirty. Commit or stash changes before benchmarking." >&2
  echo "This ensures reproducible baselines tied to specific commits." >&2
  exit 1
fi
```

**Step 2: Load config via config-dump**
Build nockchain-bench if needed (check if binary exists), then:
```bash
eval "$(cargo run -p nockchain-bench --release -- config-dump --config "$CONFIG" --profile "$PROFILE")"
```
This sets shell variables (PASSES, FIXTURES_DIR, OUTPUT_ROOT, ENABLE_CHECKPOINTING, ENVS, DOCKER_MEMORY).
Apply any CLI overrides after eval (e.g., if `--passes` was provided, override `PASSES`).

**Step 3: Create run directory**
```bash
TIMESTAMP=$(date -u +%Y-%m-%dT%H-%M-%SZ)
COMMIT_SHA=$(git rev-parse HEAD)
COMMIT_SHORT=$(git rev-parse --short HEAD)
RUN_DIR="${OUTPUT_ROOT}/${TIMESTAMP}_${COMMIT_SHORT}"
mkdir -p "$RUN_DIR"/{data,meta,logs}
```

**Step 4: Snapshot config to meta/**
```bash
cp "$CONFIG" "$RUN_DIR/meta/config-snapshot.toml"
```

**Step 5: Run benchmark matrix**
Invoke `scripts/sol_bench_matrix.sh` with resolved parameters, redirecting stderr to logs:
```bash
scripts/sol_bench_matrix.sh \
  --fixtures-dir "$FIXTURES_DIR" \
  "${BRANCH_BIN_ARGS[@]}" \
  "${DOCKER_IMAGE_ARGS[@]}" \
  --passes "$PASSES" \
  --envs "$ENVS" \
  --docker-memory "$DOCKER_MEMORY" \
  --enable-checkpointing "$ENABLE_CHECKPOINTING" \
  --output-root "$RUN_DIR/data" \
  2> >(tee "$RUN_DIR/logs/run.log" >&2)
```

**Step 6: Collect provenance and write manifest**
Collect environment info using shell commands with fallbacks:
```bash
RUSTC_VERSION=$(rustc --version 2>/dev/null || echo "unknown")
CARGO_VERSION=$(cargo --version 2>/dev/null || echo "unknown")
OS_INFO=$(uname -srm 2>/dev/null || echo "unknown")
KERNEL=$(uname -r 2>/dev/null || echo "unknown")
CPU_MODEL=$(lscpu 2>/dev/null | grep "Model name" | sed 's/.*: *//' || echo "unknown")
CPU_CORES=$(nproc 2>/dev/null || echo "0")
CPU_FREQ=$(lscpu 2>/dev/null | grep "CPU max MHz" | sed 's/.*: *//' | cut -d. -f1 || echo "null")
RAM_BYTES=$(free -b 2>/dev/null | awk '/^Mem:/{print $2}' || echo "0")
CGROUPS=$(cat /proc/self/cgroup 2>/dev/null | head -5 || echo "null")
BENCH_VERSION=$(cargo metadata --no-deps --format-version 1 2>/dev/null | jq -r '.packages[] | select(.name=="nockchain-bench") | .version' || echo "unknown")
CONFIG_SHA=$(sha256sum "$CONFIG" | cut -d' ' -f1)
```

Write `$RUN_DIR/meta/manifest.json` using jq to build proper JSON (not string concatenation):
```bash
jq -n \
  --arg schema_version "1" \
  --arg timestamp "$TIMESTAMP" \
  --arg git_commit "$COMMIT_SHA" \
  --arg git_branch "$(git rev-parse --abbrev-ref HEAD)" \
  --arg config_sha256 "$CONFIG_SHA" \
  --arg os "$OS_INFO" \
  --arg kernel "$KERNEL" \
  --arg cpu_model "$CPU_MODEL" \
  --argjson cpu_cores "$CPU_CORES" \
  --argjson ram_bytes "$RAM_BYTES" \
  --arg rustc "$RUSTC_VERSION" \
  --arg cargo "$CARGO_VERSION" \
  --arg bench_version "$BENCH_VERSION" \
  --slurpfile config_snapshot "$RUN_DIR/meta/config-snapshot.toml" \
  '{...}' > "$RUN_DIR/meta/manifest.json"
```
(For config embedding, read the resolved config as JSON from config-dump or embed the TOML as a string field.)

Handle cpu_frequency_mhz and active_cgroups as nullable fields.

**Step 7: Validate manifest using nockchain-bench** (optional -- if a validate-manifest subcommand exists from Plan 02, call it; otherwise skip validation in Bash and rely on the Rust tests)

**Step 8: Update latest symlink**

Print the run directory path, manifest location, and key provenance fields.

Create `scripts/sol_baseline_ci.sh` as a thin CI wrapper:

```bash
#!/usr/bin/env bash
set -euo pipefail

# CI wrapper: calls sol_baseline_run.sh with CI-appropriate defaults
# Adds --allow-dirty (CI checkout may modify working tree)
# Sets output root for artifact upload

SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
PROFILE="${1:---profile}"
PROFILE_VAL="${2:-full}"

# Parse arguments - pass through to sol_baseline_run.sh
ARGS=("--allow-dirty")

# Forward all arguments
while [[ $# -gt 0 ]]; do
  ARGS+=("$1")
  shift
done

exec "$SCRIPT_DIR/sol_baseline_run.sh" "${ARGS[@]}"
```

Actually, keep it simpler: accept the same flags as sol_baseline_run.sh, prepend `--allow-dirty`, and forward everything.

Make executable: `chmod +x scripts/sol_baseline_ci.sh`

Create `.github/workflows/sol-baseline.yml`:
```yaml
name: SOL Baseline
on:
  workflow_dispatch:
    inputs:
      profile:
        description: 'Benchmark profile (quick for testing, full for trusted baselines)'
        required: false
        default: 'full'
        type: choice
        options:
          - quick
          - full
      branch_bin:
        description: 'Branch binary spec (name=/path/to/binary)'
        required: true
        type: string

permissions:
  contents: read

jobs:
  baseline:
    runs-on: ubuntu-latest
    timeout-minutes: 120
    steps:
      - name: Checkout
        uses: actions/checkout@v4

      - name: Install Rust toolchain
        uses: dtolnay/rust-toolchain@stable

      - name: Cache cargo build
        uses: actions/cache@v4
        with:
          path: |
            ~/.cargo/registry
            ~/.cargo/git
            target
          key: ${{ runner.os }}-cargo-bench-${{ hashFiles('**/Cargo.lock') }}

      - name: Build nockchain-bench
        run: cargo build --release -p nockchain-bench

      - name: Build fixtures
        run: |
          if [ -f scripts/sol_build_fixtures.sh ]; then
            bash scripts/sol_build_fixtures.sh
          fi

      - name: Run baseline
        run: |
          bash scripts/sol_baseline_ci.sh \
            --profile ${{ inputs.profile }} \
            --branch-bin "${{ inputs.branch_bin }}"

      - name: Upload artifacts
        uses: actions/upload-artifact@v4
        with:
          name: sol-baseline-${{ github.sha }}-${{ github.run_number }}
          path: bench-artifacts/sol-baseline/latest/
          retention-days: 90
          if-no-files-found: error
```

Note: The workflow uses `workflow_dispatch` only (manual trigger) per CONTEXT.md decisions. Scheduled runs are Phase 3 scope.
